# رحلة سراج

تطبيق إسلامي تعليمي للأطفال من ٤ لـ ١٢ سنة. سراج شرارة نور صغيرة بتصاحب الطفل في جزيرة النور، وكل درس أو حكاية بيخلصها بينوّر جزء من الجزيرة.

- دروس: الوضوء، حركات الصلاة، أركان الإسلام، مين خلق؟
- حكايات: سيدنا يونس والحوت (من غير تجسيد)، الأمانة في الميناء (اختار انت)
- ألعاب: الذاكرة، البازل
- كنوزي: جرة النور، شرارات الخير، الملصقات، الميداليات
- ركن ولي الأمر

تصميم وتطوير: Mohamed Eldawly
